# 🚀 PPT_Saz — اسکیل هوشمند و نیتیو تولید پاورپوینت با هوش مصنوعی

<p align="center">
  <b>تولید خودکار ارائه‌های حرفه‌ای، مدرن و ۱۰۰٪ قابل ویرایش در مایکروسافت پاورپوینت (.pptx)</b><br>
  با ترنزیشن‌های سینماتیک، انیمیشن‌های ورود گام‌به‌گام، طراحی کارت‌محور و پشتیبانی کامل راست‌به‌چپ (RTL/فارسی)
</p>

---

## 🌟 ویژگی‌های برجسته (Key Features)

- **۱۰۰٪ نیتیو و قابل ویرایش (Native DrawingML):** بر خلاف ابزارهایی که اسلاید را به صورت تصویر تخت ذخیره می‌کنند، در `PPT_Saz` تمام تیترها، کادرها، کارت‌ها و شکل‌ها آبجکت‌های برداری استاندارد آفیس هستند و در پاورپوینت می‌توانید فونت، رنگ و متن آن‌ها را با یک کلیک تغییر دهید.
- **ترنزیشن‌های سینماتیک نیتیو (۴۸ افکت):** پشتیبانی واقعی از ترنزیشن‌های مایکروسافت پاورپوینت از جمله **Morph، Smooth Fade، Push، Wipe، Zoom، Reveal، Origami** و ...
- **انیمیشن‌های ورود گام‌به‌گام (۲۰۳ پریست آفیس):** انیمیشن‌های ورود جذاب (`entrance_fade`, `entrance_fly`, `entrance_wipe`) به ترتیب ورود المان‌ها (`after-previous` یا `on-click`) آماده برای ارائه حضوری بدون نیاز به تنظیم دستی.
- **تایپوگرافی دو زبانه و پشتیبانی کامل فارسی (RTL):** چینش اتوماتیک راست‌به‌چپ، تراز متن، و فونت‌های استاندارد فارسی (`Vazirmatn`, `Tahoma`, `B Nazanin`) بدون به هم ریختن حروف یا کلمات.
- **تأمین هوشمند تصویر برای هر اسلاید:** ترکیب جستجو و دانلود تصاویر باکیفیت استوک بدون واترمارک متناسب با موضوع و اتصال مستقیم به ابزارهای تولید تصویر هوش مصنوعی.
- **تم‌های بصری چشم‌نواز:** پالت‌های مدرن شرکتی، دارک استارتاپی، دانشگاهی تمیز، تکنولوژی زمردی و مینیمال.

## 🏗️ معماری سیستم (Architecture)

```
متن خام یا استوری‌بورد اسلایدها
       │
       ▼
1. تحلیلگر ساختار و کارگردان (Presentation Director)
       │
       ▼
2. طراحی بصری اسلایدها در فرمت SVG (کارت‌ها، تایپوگرافی، چیدمان RTL/LTR)
       │
       ▼
3. تأمین تصاویر متناسب با موضوع (AI Generation + Stock Fetch)
       │
       ▼
4. تخصیص ترنزیشن‌ها و انیمیشن‌های ورود به تگ‌های <g>
       │
       ▼
5. کامپایلر نیتیو DrawingML (svg_to_pptx)
       │
       ▼
فایل نهایی مایکروسافت پاورپوینت (.pptx)
```

## 📦 نصب و راه‌اندازی (Quick Start)

### پیش‌نیازها
پایتون نسخه ۳.۱۰ به بالا. پیشنهاد می‌شود از ابزار سریع `uv` یا `pip` استفاده کنید:

```bash
# کلون کردن ریپازیتوری
git clone https://github.com/HunterHill13/PPT_Saz.git
cd PPT_Saz

# نصب پیش‌نیازها
pip install -r requirements.txt
# یا با uv:
uv pip install -r requirements.txt
```

## 💻 نحوه استفاده (Usage)

### ۱. استفاده مستقیم از طریق خط فرمان (CLI)

یک فایل JSON با متن و مشخصات اسلایدها بسازید (نمونه در `examples/sample_presentation.json` موجود است):

```bash
python scripts/presentation_generator.py examples/sample_presentation.json -o my_deck.pptx
```

برای انتخاب تم و ترنزیشن خاص:

```bash
python scripts/presentation_generator.py examples/sample_presentation.json \
  -o my_deck.pptx \
  --theme modern_dark_indigo \
  -t push \
  -a auto
```

### ۲. استفاده به عنوان اسکیل در هوش مصنوعی (AI Agent Skill)

این مخزن شامل فایل استاندارد `SKILL.md` است. می‌توانید پوشه این پروژه را در مسیر اسکیل‌های محلی یا سراسری ایجنت خود (مانند Antigravity یا Claude Code) قرار دهید.

سپس در چت به راحتی به هوش مصنوعی بگویید:
> «برام یک پاورپوینت ۵ اسلایدی درباره کاربرد هوش مصنوعی در پزشکی با تم corporate_blue و ترنزیشن fade بساز.»

هوش مصنوعی به صورت خودکار:
1. ساختار اسلایدها و استوری‌بورد را طراحی می‌کند.
2. برای هر اسلاید عکس مرتبط پیدا می‌کند/تولید می‌کند.
3. انیمیشن‌ها و ترنزیشن‌ها را اضافه می‌کند.
4. اسکریپت را اجرا کرده و فایل `.pptx` را تحویل می‌دهد!

## 🎨 تم‌های موجود (Available Themes)

| نام تم | استایل | موارد استفاده |
| :--- | :--- | :--- |
| `corporate_blue` | سرمه‌ای و فیروزه‌ای تیره | ارائه‌های رسمی، مدیریتی، مهندسی |
| `modern_dark_indigo` | دارک نئونی و بنفش | ارائه‌های استارتاپی، هوش مصنوعی، وب۳ |
| `clean_academic` | سفید و آبی روشن | مقالات دانشگاهی، ارائه‌های کلاسی، پزشکی |
| `emerald_tech` | سبز زمردی مدرن | محیط زیست، بیوتکنولوژی، امور مالی |
| `warm_terracotta` | آجری و کرم گرم | هنر، معماری، علوم انسانی و دیزاین |
