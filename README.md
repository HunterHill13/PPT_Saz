## 🌟 ویژگی‌های برجسته نسخه ۲ (v2.0 Features)

- **تنوع چیدمان‌های Slidesgo بدون کشیدگی متن:** ۶ الگوی اسلاید مدرن و چشم‌نواز:
  1. `title_hero`: کاور سینماتیک با برچسب کپسولی موضوع، مشخصات سخنران و تصویر قاب‌دار
  2. `content_cards`: کارت‌های افقی با آیکون‌های وکتور رنگی و نکات کلیدی
  3. `process_steps`: فرآیند و نقشه راه گام‌به‌گام متصل با نودهای شماره‌دار (۰۱، ۰۲، ۰۳)
  4. `stats_kpi`: کارت‌های آمار و ارقام بزرگ با اعداد درشت (`+۸۵٪`، `۴.۲x`) و بج ترند
  5. `comparison`: جدول مقایسه دوراهی (روش سنتی در برابر راهکار هوشمند) با آیکون‌های تیک و ضربدر
  6. `split_image`: چیدمان دوتکه مدرن با بولت‌های آیکون‌دار و تصویر شاخص
- **آرشیو ۵,۱۳۸ آیکون وکتور محلی (Vector SVG Icons):** تطبیق خودکار هوشمند محتوای کارت‌ها با آیکون‌های وکتور بدون نیاز به اینترنت.
- **تایپوگرافی اختصاصی یکان‌بخ (Yekan Bakh):** تبدیل و نصب رسمی تمام ۸ وزن فونت یکان‌بخ در ویندوز و فعال‌سازی به عنوان فونت اصلی در تم‌ها.
- **۱۰۰٪ نیتیو و قابل ویرایش (Native DrawingML):** تمام کادرها، متون و شکل‌ها در پاورپوینت کاملاً قابل ادیت و تغییر رنگ هستند.
- **ترنزیشن‌های سینماتیک نیتیو (۴۸ افکت):** Morph, Fade, Push, Wipe, Zoom, Reveal و ...
- **انیمیشن‌های ورود گام‌به‌گام (۲۰۳ پریست آفیس):** ورود پشت سر هم عناوین، کارت‌ها و تصاویر با حالت `after-previous`.

## 🏗️ معماری سیستم

```
متن و استوری‌بورد اسلایدها
       │
       ▼
1. کارگردان چیدمان (انتخاب از میان ۶ الگوی Slidesgo)
       │
       ▼
2. تطبیق خودکار آیکون‌های وکتور (icon_mapper.py از میان ۵۰۰۰+ آیکون)
       │
       ▼
3. تأمین تصاویر متناسب با موضوع (AI Generation + Stock Fetch)
       │
       ▼
4. رندر وکتور SVG با تایپوگرافی یکان‌بخ (Yekan Bakh) و پترن‌های تزئینی
       │
       ▼
5. کامپایلر نیتیو DrawingML + تزریق ترنزیشن و انیمیشن (svg_to_pptx)
       │
       ▼
فایل نهایی مایکروسافت پاورپوینت (.pptx)
```

## 📦 نصب و راه‌اندازی (Quick Start)

```bash
git clone https://github.com/HunterHill13/PPT_Saz.git
cd PPT_Saz

pip install -r requirements.txt
# یا با uv:
uv pip install -r requirements.txt
```

## 💻 نحوه استفاده (Usage)

### ۱. اجرای مستقیم از طریق خط فرمان:

```bash
# تولید ارائه ۵ اسلایدی کامل با تم سازمانی و ترنزیشن Fade:
python scripts/presentation_generator.py examples/sample_presentation.json -o my_slides.pptx --theme corporate_blue -t fade -a auto
```

### ۲. استفاده به عنوان اسکیل هوش مصنوعی:
کافیست در محیط گفتگوی هوش مصنوعی (Antigravity یا Claude) بگویید:
> «برام یک پرزنتیشن ۵ اسلایدی حرفه‌ای با موضوع تحول دیجیتال در سلامت با فونت یکان‌بخ و چیدمان‌های متنوع اسلایدزگو بساز.»
